# The Hawthorne Legacy

My Sims 4 ten-generation legacy tracker. Runs offline, everything is saved in the browser.

## Running it

Open `index.html`, or serve the folder (`py -m http.server 8765`) and go to `http://localhost:8765`. Saving works more reliably on a local server than on `file://`. Export a backup from Settings now and then.

## How the challenge works

- **Generations**: ten heirs, each with a vibe, goals, skills and lot challenges. Everything is editable.
- **Core goals**: if the heir hasn't finished every core goal by elder, the firstborn loses the inheritance, it goes to the secondborn, and the generation is marked as failed (−50).
- **Vibe test**: each generation has one test that protects its vibe. Pass it for points, fail it and lose them.
- **Fate & chaos**: when something happens on its own in the game (someone walks in, a breakup, a death, a fire…), pick the event and roll. The result is binding: finish it for points, fail it and lose them.
- **Family fate and weekly misfortune**: the original randomizers, still there.
- **Side challenges**: other challenges stacked on top (like the Grim Reaper's child). When two clash, roll: the winner is followed, the loser is broken.
- **Family box**: the objects that define the family. Objects go in, nothing comes out.

## Updating from v6

Your saved progress is kept. Text you never edited is replaced with the new wording; anything you changed stays as you wrote it. New features (vibe tests, chaos rolls, side challenges, core goals) are added on top.
